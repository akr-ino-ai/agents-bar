# Agents Bar

Windows の画面上部に常駐し、**Claude Code と Codex の「許可待ち」「質問待ち」をまとめて確認して、その場で回答する**ための小さなバーです。別の作業をしていても、エージェントが止まっていることに気づけます。

このアプリ自身は、セッションの内容や許可の内容を外部へ送信しません。通信は自分のPCの中だけです（利用量表示のために起動する CodexBar については「プライバシー」を参照）。

- 版: `0.1.0-beta.2`（無償のベータ版。beta.1 からの変更点は Releases の本文を参照）
- 対応OS: Windows 11 x64

> **ベータ版です。** 無償・評価目的で提供します。無保証で、自動更新はありません。実行ファイルには署名していないため、起動時に Windows SmartScreen が警告します。利用前に[ベータ利用条件](BETA_TERMS.md)をお読みください。

## できること

- Claude Code と Codex の**複数セッションの状態**を一覧表示（実行中／許可待ち／回答待ち／完了／失敗／終了／更新停止）
- **許可要求の内容**（対象ツール、コマンド、作業フォルダ、理由に加え、Web 取得の URL、MCP ツールの引数、ファイル編集の変更前後など入力の要約）を確認して、**「許可」「拒否」をバーで回答**。カードには要求 ID の末尾 4 桁と受信時刻が付き、似た要求を見分けられます
- Claude Code の**選択式の質問（1問のとき）にバーで回答**
- 新しい許可待ち・質問待ちを**音とバーの強調で通知**
- セッションのカードから**発生元のアプリを前面に出す**
- CodexBar（第三者製）を導入している場合、**利用量の残り**を表示

## 必要なもの

| | 内容 |
| :-- | :-- |
| OS | Windows 11 x64 |
| **Node.js** | **22.12 以上**（LTS の 24 系を推奨）が PATH 上にあること。**フックの実行に必須**です |
| エージェント | Claude Code（Claude Desktop の Code タブ、または CLI）／ Codex（Windows デスクトップアプリ、または CLI） |
| 任意 | CodexBar（利用量表示に使用。未導入なら `--%` と表示します） |

## 重要な前提 — 承認カードが出る条件

**このアプリは、エージェントが実際に許可を求めたときだけカードを出します。** エージェント側が自分で判断して実行する設定になっていると、カードは出ません。アプリの不具合ではありません。

- **Claude Code**: 権限モードを**「手動（変更前に常に確認する）」**にしてください。既定の「自動」では、Claude 自身が権限を判断するためカードがほとんど出ません。
- **Codex**: サンドボックスの**書き込み可能範囲（作業フォルダと一時ディレクトリ）を超える操作**だけが承認の対象です。範囲内の操作（例: 一時フォルダへの書き込み）では、Codex が承認を求めないため、カードは出ません。
- **Codex デスクトップアプリ（ChatGPT アプリ）は、会話に作業フォルダーを設定してください。** フォルダーを設定した会話では、サンドボックス外の操作の承認がこのアプリに届きます。フォルダーを設定していない会話では、Codex が別の方式（先に書き込み権限を依頼する方式）で確認するため、承認はアプリ側のダイアログだけに出て、このアプリには届きません（2026-10-19 時点の ChatGPT デスクトップアプリで確認）。
- **Codex CLI の起動フォルダー**: プロジェクトのフォルダーで起動してください。`C:\Windows\System32` やユーザーのホームフォルダー（`C:\Users\<ユーザー名>`）で起動すると、Codex のサンドボックスの準備に失敗して承認が正しく動かないことがあります（このアプリの不具合ではありません）。

## 導入手順

1. Releases から `Agents-Bar-<版>-win-x64.zip` をダウンロードし、任意のフォルダーに展開して `Agents Bar.exe` を起動します。インストーラーはありません。
2. **ダウンロードした zip の確認（推奨）**: PowerShell で `Get-FileHash .\Agents-Bar-<版>-win-x64.zip -Algorithm SHA256` を実行し、Releases に記載の SHA-256 と一致することを確かめます。署名していない配布物なので、改ざんされていないことはこの照合で確認します。
3. 起動します。SmartScreen が警告したら「詳細情報」→「実行」を選びます。署名していないため出る警告です。
4. 画面上部中央にバーが出て、通知領域（タスクトレイ）にアイコンが入ります。
5. トレイアイコンを右クリック →「設定…」→ 左の**「連携」**を開きます。
6. **Node.js の状態**が表示されます。問題がなければ**「両方にフックをインストール」**を押します。確認のダイアログが出るので、内容を読んで進めます。
7. **Codex を使う場合は、フックの信頼が必要です。** ターミナルで `codex` を起動してから `/hooks` を実行し、フックを信頼してください。フックマネージャーは Codex CLI の機能です。デスクトップアプリの入力欄に `/hooks` と書いても開きません（通常の質問としてモデルに渡ります）。信頼したあとは、デスクトップアプリのセッションでもフックが動きます。

**設定ファイルの変更について。** フックの導入・解除は、`~/.claude/settings.json` と `~/.codex/hooks.json` を書き換えます。**変更前に、同じ場所へ日時付きのバックアップを作成します。** 追加するのはこのアプリのフック項目だけで、既存の設定はそのまま残ります。導入・解除はどちらも、画面のボタンと Windows の確認ダイアログの両方を通ったときだけ実行します。起動しただけでは何も書き換えません。

## 使い方

バーにカーソルを合わせると展開し、**「対応が必要」「実行中」「最近完了」**の順に表示します。

**承認への回答** — 「対応が必要」のカードで、対象ツール・コマンド・作業フォルダ・理由を確認してから「許可」または「拒否」を押します。回答は元のセッションへ返ります。**このアプリが自動で許可することはありません。**

**Codex の承認をどこで回答するか** — 初期値は**「Codex標準で承認」**です。バーは通知と表示だけを行い、回答は Codex 本来の画面で行います（スマホの Remote での承認を妨げないための既定値です）。バーで直接回答したい場合は、設定の「連携」→「Codexの承認先」を「Agents Bar で承認」に変えます。展開パネルのドロップダウンからは、アプリを再起動するまでの一時変更ができます。

**質問への回答** — Claude Code の選択式の質問が1問のときは、バーで選んで送信できます。**Codex の質問回答は実験機能で、初期値は無効です。** 有効にするには設定の「連携」→「実験機能」を切り替えます。無効のときは、Codex 本来の質問画面で回答します。

**通知** — 新しい許可待ち・質問待ちで音が1回鳴ります。設定の「通知とサウンド」で、イベントごとに音・バーの強調・自動展開・Windows通知を切り替えられます（Windows 通知の初期値はオフです）。

## 既知の制限

- **自動更新はありません。** 新しい版は手動で入れ替えます。**入れ替える前に、トレイから旧版を終了してください。** 旧版が動いていると、新しい版の `Agents Bar.exe` を起動しても即座に終了します。新しい zip は別のフォルダーに展開し、旧版のフォルダーは不要になってから削除します。
- **署名していないため、SmartScreen が警告します。**
- **Codex の質問回答（実験機能）は、Codex の公式な方法ではありません。** Codex 側の変更で効かなくなることがあります。効かなくなった場合は、設定で無効にして Codex 本来の質問画面で回答してください。
- **カードをクリックしても、該当のタブや会話までは戻れません。** 発生元のアプリを前面に出すところまでです。エージェント側にセッション単位で開く公式な方法がないためです。
- **Codex デスクトップアプリで会話に作業フォルダーを設定していないと、承認はこのアプリに届きません。** その会話では Codex が「先に書き込み権限を依頼する」方式で確認し、ダイアログはアプリ側だけに出ます。回答はアプリ側で行ってください。許可後の実行は通常どおりです。
- **「Codex を開く」「Claude を開く」は、そのエージェントのデスクトップアプリを前面に出します。** Codex CLI など、ターミナルで動かしているセッションのカードでも、前面に出るのはデスクトップアプリ（ChatGPT アプリ）です。ターミナルのウィンドウやタブは前面に出ません。
- **Codex 標準へ回した承認・質問の通知カードは、回答済みでも最大約4分表示されたままになります。** Codex 標準へ回した時点でこのアプリの役目は終わっており、あなたが Codex 側で何を答えたかを知る手段がないためです。その間、要対応の件数は実際より多く見えます。
- **Claude Code のデスクトップアプリは、このアプリのカードと同時に自分の許可ダイアログも表示します。** アプリ側のダイアログで先に回答すると、バーのカードが最大約4分残ります。
- **利用量の表示には CodexBar（第三者製）が必要です。** 未導入や取得失敗のときは `--%` と表示します。0% や推定値では代用しません。
- 表示は**主画面の上部中央**に固定です。複数モニターでも移動できません。
- **画面は日本語のみ**です。
- 実行中のセッションは30分更新がないと「更新停止」になり、要対応がなければ24時間後に一覧から消えます。**回答待ちの要求は、一覧の整理では消えませんが、約4分以内に回答がないとカードが消え、各エージェント本来の許可画面に戻ります（自動許可はしません）。**
- **カードに出る入力の要約は、1項目200文字・1枚6項目までです。** 超えた分は「…（全N文字）」「他 n 個の引数は表示していません」と示します。全文は各エージェント側の画面で確認してください。
- **秘密値らしき文字列（`api_key=`、`token:`、`Authorization: Bearer` など）は、表示上 `***` に置き換えます。** 判定は経験則で、隠しきれない形や、秘密でない語を隠す場合があります。表示の置き換えだけで、許可・拒否の判定やエージェントへの回答には影響しません。
- フック設定のバックアップは自動で消えません。不要になったら手動で削除してください。
- 対象は、このPC上で動く Claude Code と Codex のセッションだけです。SSH 先・別PC・クラウドのセッションには対応していません。

## 安全のための動作

- **アプリが停止しているとき、通信できないとき、時間切れのときは、自動で許可しません。** 何も出力せず、各エージェント本来の許可画面に戻します。
- 危険そうな操作をこのアプリが独自に判断して自動許可することはありません。
- 1件の回答が、別のセッションや別の要求に適用されることはありません。

## プライバシー

- このアプリ自身は外部へ接続しません。セッションの内容、許可の内容、プロンプト、コマンドを外部へ送信しません。
- **例外: 利用量表示（初期値は有効）。** 導入済みの CodexBar CLI があれば、起動時と5分以上の間隔でそれを起動して利用量を読み取ります。CodexBar は利用量を取得するために Anthropic／OpenAI のサービスと通信することがあります。不要なら設定で利用量表示を無効にしてください。CodexBar を導入していなければ何も起動しません。
- 利用状況の収集（テレメトリ）はありません。アカウント登録もありません。
- 通信はこのPC内（127.0.0.1）だけで、毎回変わるトークンで認証します。
- 設定は `%APPDATA%\windows-ai-agent-control-bar` に保存します。起動中は、接続先のポートとトークンを書いた `runtime.json` を `%APPDATA%\ai-agent-control-bar` に置きます（通常はアプリ終了時に削除されます）。
- 通常のログに、プロンプト全文・コマンド全文・環境変数・認証情報は保存しません。

## アンインストール

1. 設定の「連携」から、Claude と Codex それぞれの**「フックをアンインストール」**を押します。このアプリが追加した項目だけを取り除き、変更前にバックアップを作ります。
2. zip を展開したフォルダーを削除します。
3. 設定を消す場合は `%APPDATA%\windows-ai-agent-control-bar` フォルダーを削除します。`%APPDATA%\ai-agent-control-bar` フォルダー（`runtime.json` の置き場）も削除します。
4. 手順1で作られたバックアップファイル（`*.controlbar-backup-*.json`）は残ります。不要なら手動で削除してください。
5. 自動起動を有効にしていた場合、展開先フォルダーを移動・削除すると自動起動の登録が無効になります。移動した場合は、設定で自動起動を入れ直してください。
